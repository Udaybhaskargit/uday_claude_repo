# E9-S4 — Expose the admin API for queues, overrides, and audit trail

**Epic:** E9 — REST API
**Layer:** API
**Group:** F
**Depends on:** E8-S2

## Description

Expose the admin dashboard endpoints: claim queue filtered by status/product, fraud alert queue, payout audit trail, and the override action, wired to E8-S2.

## Acceptance Criteria

1. Given X-Role: ADMIN, when GET /api/admin/claims?status=MANUAL_REVIEW&product=MOTOR is called, then only matching claims are returned.
2. Given X-Role: ADMIN, when GET /api/admin/payouts is called, then the response lists every Settlement row with claim id, amount, and timestamp as an immutable audit trail.
3. Given X-Role: ADMIN, when POST /api/admin/claims/{id}/override is called with a command and reason code, then the response is 200 and the created AdminOverride is visible in a subsequent GET /api/admin/claims/{id}/overrides.
4. Given X-Role: ASSESSOR, not ADMIN, when any /api/admin/* endpoint is called, then the response is 403.
