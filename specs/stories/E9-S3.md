# E9-S3 — Expose the assessor workbench API

**Epic:** E9 — REST API
**Layer:** API
**Group:** H
**Depends on:** E5-S3, E6-S2, E8-S1

## Description

Expose the fraud-alert queue and per-claim detail/decision-submission endpoints for the Assessor role, wired to E5 and E6.

## Acceptance Criteria

1. Given X-Role: ASSESSOR, when GET /api/claims/fraud-alerts is called, then the response lists only claims whose latest FraudScreening.flagged is True.
2. Given a claim in MANUAL_REVIEW, when GET /api/claims/{id}/workbench is called, then the response includes the fraud score and breakdown, the assessed payable_amount, and decision-rationale fields.
3. Given a claim in MANUAL_REVIEW, when POST /api/claims/{id}/decision is called with an assessor's outcome and reason code, then the response is 200 and a new append-only Decision row is created with decided_by set to the assessor's actor id.
