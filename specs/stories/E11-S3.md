# E11-S3 — Build the assessor workbench UI

**Epic:** E11 — Internal Portal
**Layer:** UI
**Group:** J
**Depends on:** E11-S2

## Description

Detail view for an assessor to review a claim's fraud flags and assessed amount and submit a decision, wired to E9-S3.

## Acceptance Criteria

1. Given a claim in MANUAL_REVIEW, when the workbench renders, then it displays the fraud score and breakdown alongside the computed payable_amount.
2. Given the assessor selects an outcome and reason code and submits, when the API call succeeds, then the UI shows a confirmation and the claim is removed from the pending workbench list.
3. Given the assessor attempts to submit without selecting an outcome, when Submit is clicked, then a validation message blocks the call.
