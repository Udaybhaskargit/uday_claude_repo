# E11-S1 — Build the document verification queue UI

**Epic:** E11 — Internal Portal
**Layer:** UI
**Group:** H
**Depends on:** E9-S2

## Description

Desktop-oriented queue listing claims in DOCS_PENDING with per-claim-type checklist toggles, wired to E9-S2.

## Acceptance Criteria

1. Given the queue loaded, when rendered, then only claims in DOCS_PENDING appear, grouped or filterable by claim type.
2. Given a checklist item toggled to VERIFIED, when the last outstanding item for a claim is verified, then that claim disappears from this queue on the next refresh.
3. Given the queue is accessed under an X-Role: CUSTOMER context, when requested, then the UI does not render the queue and shows an access-denied state instead.
