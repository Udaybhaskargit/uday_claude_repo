# E1-S3 — Define reason codes and domain exceptions

**Epic:** E1 — Domain Foundation
**Layer:** Types
**Group:** A
**Depends on:** (none)

## Description

Define the closed set of reason codes and typed exceptions referenced throughout the BRD (PolicyNotActiveException, DuplicateClaimException, and the InvalidClaimStateException contract) so services raise consistent, typed errors instead of ad hoc strings.

## Acceptance Criteria

1. Given the ReasonCode enum, when enumerated, then it contains exactly POLICY_INACTIVE, ZERO_PAYABLE_AMOUNT, FRAUD_FLAG, AUTO_APPROVED_LOW_RISK, HIGH_VALUE_REVIEW, DOCS_INCOMPLETE.
2. Given PolicyNotActiveException, when raised, then it carries the policy_number and incident_date that failed validation.
3. Given DuplicateClaimException, when raised, then it carries the policy_number and incident_date of the conflicting claim.
4. Given any domain exception in this module, when caught by the API layer, then its type maps to exactly one HTTP status code (409 for duplicate, 422 for policy-inactive, 409 for invalid transition).
