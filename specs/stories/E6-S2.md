# E6-S2 — Implement the decision engine

**Epic:** E6 — Assessment & Decision
**Layer:** Service
**Group:** G
**Depends on:** E6-S1, E5-S3

## Description

Determine AUTO_APPROVE / MANUAL_REVIEW / REJECT with an attached reason code from the assessed amount and fraud flag, per AC-06 and BRD section 11 thresholds.

## Acceptance Criteria

1. Given payable_amount == 0, when decided, then the outcome is REJECT with reason code ZERO_PAYABLE_AMOUNT.
2. Given a fraud-flagged claim with nonzero payable_amount, when decided, then the outcome is MANUAL_REVIEW with reason code FRAUD_FLAG.
3. Given an unflagged claim with payable_amount of 30000, at or below the 50000 ceiling, when decided, then the outcome is AUTO_APPROVE with reason code AUTO_APPROVED_LOW_RISK.
4. Given an unflagged claim with payable_amount of 75000, above the ceiling, when decided, then the outcome is MANUAL_REVIEW with reason code HIGH_VALUE_REVIEW.
5. Given a decision result, when persisted, then the Decision row is append-only and records decided_by as either 'system' or an assessor actor id.
