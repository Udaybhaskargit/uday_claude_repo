# E11-S4 — Build the admin dashboard UI

**Epic:** E11 — Internal Portal
**Layer:** UI
**Group:** G
**Depends on:** E9-S4

## Description

Desktop dashboard for queue-by-status/product, fraud alerts, payout audit trail, and the override action, wired to E9-S4.

## Acceptance Criteria

1. Given the dashboard loaded, when the status/product filters are changed, then the claim queue table updates to match without a full page reload.
2. Given the payout audit trail section, when rendered, then rows are shown in reverse-chronological order and are read-only with no edit controls.
3. Given the override action on a selected claim, when submitted without a reason code, then the form blocks submission with a validation message.
4. Given a successful override, when the API confirms it, then the new override entry appears in that claim's audit history within the dashboard.
