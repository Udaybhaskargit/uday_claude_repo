# E10-S1 — Build the FNOL submission form

**Epic:** E10 — Customer Portal
**Layer:** UI
**Group:** J
**Depends on:** E9-S1

## Description

Responsive (mobile/tablet/desktop) form for a customer to file a claim: policy number, incident date, claim type selector, and the per-type document checklist, calling E9-S1.

## Acceptance Criteria

1. Given the form loaded at a mobile viewport of 375px wide, when rendered, then all fields remain reachable without horizontal scrolling.
2. Given a claim type of HEALTH selected, when the checklist section renders, then it shows exactly Hospital bill and Discharge summary toggles, not motor or life document labels.
3. Given a submission with a missing required field, when Submit is clicked, then an inline validation message appears and no API call is made.
4. Given a successful submission, when the API returns 201, then the UI navigates to the claim tracker view for the new claim id.
