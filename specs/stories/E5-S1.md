# E5-S1 — Enforce the per-claim-type document checklist

**Epic:** E5 — Document Verification & Fraud Screening
**Layer:** Service
**Group:** F
**Depends on:** E4-S1

## Description

Enforce that a claim cannot leave DOCS_PENDING until every checklist item for its claim type is VERIFIED, with the required documents varying by claim type. This is AC-03.

## Acceptance Criteria

1. Given a motor claim with POLICE_FIR still MISSING, when check_documents_complete() is called, then it returns False and the claim remains DOCS_PENDING.
2. Given a motor claim with both POLICE_FIR and INVOICE set to VERIFIED, when checked, then it returns True and the claim transitions to FRAUD_SCREENING.
3. Given a health claim, when its checklist is evaluated, then only HOSPITAL_BILL and DISCHARGE_SUMMARY are considered, ignoring motor/life document types.
4. Given an attempt to mark a document type that is not part of the claim's own claim-type checklist, when verify_document() is called, then it raises a typed validation error.
