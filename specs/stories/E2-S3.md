# E2-S3 — Centralize application and role configuration

**Epic:** E2 — Business Rule Configuration
**Layer:** Config
**Group:** B
**Depends on:** E1-S1

## Description

Centralize environment/app configuration (DB file path, backend/frontend ports, and the list of valid X-Role values accepted by the auth boundary) so no other layer reads environment variables directly.

## Acceptance Criteria

1. Given AppConfig, when loaded, then it exposes db_path, backend_port (8000), and frontend_port (5173).
2. Given AppConfig.valid_roles, when enumerated, then it equals exactly CUSTOMER, ASSESSOR, ADMIN, matching the Role enum in Types.
3. Given a missing required environment variable with no default, when AppConfig loads, then it raises a typed config error naming the missing variable.
