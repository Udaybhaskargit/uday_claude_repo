# E11-S2 — Build the fraud alert queue UI

**Epic:** E11 — Internal Portal
**Layer:** UI
**Group:** I
**Depends on:** E9-S3

## Description

Desktop queue listing claims currently flagged by fraud screening, wired to E9-S3.

## Acceptance Criteria

1. Given the queue loaded, when rendered, then each row shows the fraud score, the triggered rule names, and a link into the assessor workbench for that claim.
2. Given a claim's flag is cleared by a later re-screening, when the queue refreshes, then that claim no longer appears.
3. Given the queue is accessed under an X-Role: CUSTOMER context, when requested, then the UI does not render the queue and shows an access-denied state instead.
