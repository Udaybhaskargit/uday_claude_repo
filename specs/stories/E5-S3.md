# E5-S3 — Persist fraud screenings and gate the pipeline

**Epic:** E5 — Document Verification & Fraud Screening
**Layer:** Service
**Group:** F
**Depends on:** E5-S2, E3-S4

## Description

Persist every fraud screening run as an append-only FraudScreening record (score, breakdown, threshold-at-time, flagged) and gate the claim's transition into ASSESSMENT vs MANUAL_REVIEW accordingly.

## Acceptance Criteria

1. Given a scored claim, when the result is persisted, then the FraudScreening row stores the threshold that was active at scoring time, not the current config value.
2. Given a flagged=True result, when persisted, then the claim moves toward MANUAL_REVIEW with reason code FRAUD_FLAG.
3. Given a flagged=False result, when persisted, then the claim moves toward ASSESSMENT.
4. Given two screenings on the same claim, for example after a retry, when both are persisted, then both rows remain independently queryable with no overwrite, per NFR-02.
