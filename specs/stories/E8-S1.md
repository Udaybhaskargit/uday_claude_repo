# E8-S1 — Implement the stubbed role-based auth dependency

**Epic:** E8 — Auth Boundary & Admin Override
**Layer:** API
**Group:** C
**Depends on:** E1-S1, E2-S3

## Description

A FastAPI dependency reads the X-Role header and an actor id, validates the role against AppConfig.valid_roles, and injects an ActorContext into every controller. This is the auth boundary chosen in BRD section 7.1, satisfying NFR-04.

## Acceptance Criteria

1. Given a request with X-Role: ASSESSOR and a valid actor id, when the dependency resolves, then the route handler receives an ActorContext with role=ASSESSOR and the given actor_id.
2. Given a request with X-Role: SUPERVISOR, a value not in valid_roles, when the dependency resolves, then the request is rejected with HTTP 401 before the route handler runs.
3. Given a request missing the X-Role header entirely, when the dependency resolves, then it is rejected with HTTP 401.
4. Given a route decorated with require_role(ADMIN), when a request arrives with X-Role: ASSESSOR, then it is rejected with HTTP 403.
