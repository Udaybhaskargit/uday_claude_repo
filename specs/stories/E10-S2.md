# E10-S2 — Build the claim tracker view

**Epic:** E10 — Customer Portal
**Layer:** UI
**Group:** J
**Depends on:** E9-S1

## Description

Read-only status view for a customer's claim: current status, decision outcome and reason codes once decided, and outstanding/missing documents.

## Acceptance Criteria

1. Given a claim in DOCS_PENDING, when the tracker renders, then it lists each outstanding document type distinctly from verified ones.
2. Given a claim with outcome MANUAL_REVIEW and reason code HIGH_VALUE_REVIEW, when rendered, then the human-readable reason text, not just the raw code, is displayed.
3. Given a SETTLED claim, when rendered, then the settled payout amount is displayed and a Dispute this claim action is visible.
4. Given a claim that is not SETTLED, when rendered, then no dispute action is shown.
