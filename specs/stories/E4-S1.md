# E4-S1 — Implement the FNOL intake service

**Epic:** E4 — Claim Intake
**Layer:** Service
**Group:** E
**Depends on:** E3-S3

## Description

Accept a first-notice-of-loss submission (policy number, incident date, claim type) for any of the 3 claim types and create the initial Claim plus its per-type ClaimDocument checklist rows, satisfying AC-01.

## Acceptance Criteria

1. Given a valid motor FNOL payload, when submit_fnol() is called, then a Claim is created with claim_type='MOTOR' and two ClaimDocument rows (POLICE_FIR, INVOICE) each MISSING.
2. Given a valid health FNOL payload, when submitted, then the checklist rows are exactly HOSPITAL_BILL and DISCHARGE_SUMMARY.
3. Given a valid life FNOL payload, when submitted, then the checklist row is exactly DEATH_CERTIFICATE.
4. Given a successful submission, when it completes, then the claim's initial status is INTAKE and, once checklist rows are attached, it transitions to DOCS_PENDING.
