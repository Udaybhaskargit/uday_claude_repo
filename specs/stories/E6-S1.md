# E6-S1 — Implement the assessment service

**Epic:** E6 — Assessment & Decision
**Layer:** Service
**Group:** E
**Depends on:** E3-S3, E3-S2, E2-S2

## Description

Compute payable_amount = min(claim_amount, sum_insured) minus deductible minus co_pay in fixed-point Decimal, enforcing the invariant payable_amount >= 0. This is AC-05 and NFR-01.

## Acceptance Criteria

1. Given a motor claim with claim_amount 40000 and sum_insured 100000, when assessed, then payable_amount equals 35000 (40000 minus the 5000 deductible, no co-pay).
2. Given a health claim with claim_amount 20000, when assessed, then the 1000 deductible and 10% co-pay of 19000 (=1900) yield payable_amount 17100.
3. Given a life claim with claim_amount 200000 and sum_insured 150000, when assessed, then payable_amount equals min(200000,150000) = 150000 with no deductions.
4. Given inputs that would mathematically compute negative, when assessed, then payable_amount is clamped to 0 and is never negative.
5. Given any assessment result, when its type is inspected, then payable_amount is a Decimal and the computation used no float arithmetic at any step.
