# ClaimFlow — Claims Intake, Assessment & Settlement Platform

Horizon Insurance FNOL-to-settlement pipeline for motor, health, and life products: intake, document
checks, fraud screening, assessment, decision, and payout.

## Capstone Constraints (BC-AINE-005) — read before doing anything

- **No-Hand-Coding Rule:** all production code, tests, and migrations must be generated by Claude
  Code agents. Hand-edits are limited to specs, CLAUDE.md, agent definitions, hooks, skills, and
  other substrate files.
- **Spec-Is-Truth Rule:** when a spec and code disagree, the spec wins — update the spec
  deliberately, then regenerate the code.
- **PR-Only Merge Rule:** no direct commits to `main`. All changes flow through agent-reviewed pull
  requests (at least 3 PR-driven merges required).
- **Synthetic-Data Rule:** tiny dummy data only. Never use real/confidential customer data.
- Every acceptance criterion (AC-01..AC-10) must have at least one test that references its AC-N
  identifier in the test name or a tag/marker.

## Quick Reference

**Backend:** `cd backend && pytest -x -q` | `ruff check --fix .` | `mypy src/`
**Frontend:** `cd frontend && npm test` | `npm run lint` | `npm run typecheck` | `npx playwright test`
**Full stack:** `./init.sh` installs deps and starts backend (`:8000`) + frontend (`:5173`) locally.

## Architecture

Strict layered architecture: Types → Config → Repository → Service → API → UI.
One-way dependencies only. See `.claude/architecture.md` for full rules.

## Code Style

- TDD mandatory: test first, then implement
- 100% meaningful coverage target, 80% floor
- Functions < 50 lines, files < 300 lines
- Static typing everywhere (zero `any`, full type hints)
- Money math (payout/deductible/co-pay) in fixed-point `Decimal`, never `float`
- Claim records, fraud scores, assessments, settlements: append-only, never mutate in place
- PII (health data, claim narratives, document content) must never be written to logs
- See `.claude/skills/code-gen/SKILL.md` for full rules

## Git

No direct commits to `main` — PR-only.
